# StreamVista Home UX Redesign

## Goal
Make the public StreamVista home page immediately understandable to filmmakers, creators, and visual teams.

## Product sentence
Your visual work, from idea to release.

## Four-step mental model
1. Create — Make your project
2. Protect — Protect your work
3. Connect — Find the right buyer
4. Distribute — Deliver everywhere

## UX rules
- Prefer plain language over infrastructure terminology.
- Keep one primary call to action: Start creating.
- Keep one secondary action: See how it works.
- Explain capabilities with short outcome-focused sentences.
- Keep Crayons Bridge as the commercial path, but explain it in business language.
- Avoid dashboard-like metrics and decorative system diagrams on the public home page.
- Preserve existing routes and backend contracts.
- Keep the premium dark aesthetic, but reduce visual noise, labels, microcopy, and motion.
- Do not present an unfinished workspace as a finished product.

## Canonical routes
- /creator-studio — create and manage projects
- /crayons-bridge — rights, buyers, deals and commerce
- /crayons-loop — delivery and distribution
- /pricing — plans
- /login — access

## Verification
This document describes UX only. It does not certify backend production readiness. Production readiness still requires the release evidence gates documented elsewhere in this repository.
