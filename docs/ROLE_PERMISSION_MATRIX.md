# Role Permission Matrix

| Role | Access Level | Key Capabilities |
|---|---|---|
| `platform_owner` | Full Access | Can do everything. Cannot be deleted. |
| `founder` | Full Access | Complete system administration and oversight. |
| `super_admin` | Full Access | Global admin for all features including Users and Finance. |
| `admin` | Elevated | Can manage Titles, Campaigns, Analytics. Cannot access Finance/Users. |
| `creator_partner` | Scoped | Can manage own Titles, Drafts, Uploads, and view own Analytics. |
| `buyer` | Restricted | Can only view and screen assigned Titles in Buyer Dashboard. |
| `finance` | Specialized | Can access Payments & Revenue dashboards and reports. |
| `qc_staff` | Specialized | Can access QC pages for asset review and approval. |
| `legal_staff` | Specialized | Can access Legal pages for contract and rights verification. |
| `support_staff` | Restricted | Can access Settings and (future) support tickets. |
